# ADR-0005 — Approval UI surface for v1

**Status:** Proposed · **Date:** 2026-09-07

## Context
The gate needs a human surface: CLI, Slack app, or a minimal web page. It must capture who approved, when, and which exact proposal hash — and must distinguish fast-path from strict review. The Spring Boot approval API was explicitly deferred out of v1.
